# WealthOS usability refinement plan (completed in 0.6.4)

Problem: explanatory paragraphs, competing Add buttons and equally prominent technical details obscured the main workflows.

Implementation plan: simplify the five main destinations; use one categorized Add menu; put balances and primary actions first; disclose assumptions, source inputs and revision history on demand; reduce form hints to contextual help. Keep incomplete, estimated, stale and provisional states visible. Preserve all calculations, schema, encryption and stored records.

Verification: compile native Android code, run navigation and existing financial workflow regressions, inspect rendered fictional-data screens in light/dark themes and larger text, run lint and release assembly, then verify a same-signer update against the existing fictional release vault. No physical phone access is part of this work. Verified results and the final artifacts are recorded in [0.6.4](RELEASE_0_6_4.md).
