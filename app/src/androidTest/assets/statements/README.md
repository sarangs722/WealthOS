# Fictional statement fixtures

Both XLS files are independently generated by `core:imports/HdfcStatementsTest.xlsNativeNumericMoneyAndSpacedMergedCardColumnsWork`. They contain fictional people, merchants, references and amounts. They are not sanitized copies of user statements. The tests reproduce only generic verified headers/column spacing and date/amount conventions.

Running `:core:imports:test` generates reproducible inputs under that module's ignored `build/fictional-fixtures/` directory. Copy those generated fixtures here deliberately when the layout test changes. These assets belong exclusively to the instrumentation APK; release packaging validation rejects statement test assets in the financial application.
